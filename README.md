# Modelo Financiero Mayorista Raíz Latina — V13.4

Base: aplicación financiera de producción con PostgreSQL/Neon.

## Cambios V13.4
- Dashboard con 7 indicadores: Ventas acumuladas, Costo productos, Costo envío, Costo impuestos, Gastos registrados, Resultado estimado y Utilidad estimada.
- Impuestos recaudados y utilidad de impuestos permanecen disponibles en Reportes detallados.
- Observación visible directamente en el listado de Pedidos.
- Botón "Ver Observaciones" en Envíos pendientes.
- Estado "CONFIRMADO" disponible en Envíos pendientes.
- Cliente de Nueva cotización con búsqueda integrada en el propio selectbox Cliente.
- Listado de Cotizaciones con botones directos Descargar y Editar por fila.
- PDF de cotización rediseñado: fondo blanco, logo a color más grande, MAYORISTAS bajo el logo, encabezado internacional, datos vendedor/cliente sin cajas, resumen financiero simplificado y total resaltado en amarillo.
- Se conserva la lógica financiera y la persistencia en Neon.
